- assets/logo.png

Conteúdo provisório a substituir:
- imagens do Unsplash
- números XX+
- depoimentos demonstrativos
- chave Pix
- WhatsApp e e-mail reais
- link real do Instagram
- logos dos apoiadores

A tipografia Pagkaki e Now foi mantida como primeira escolha no CSS. 
Como são fontes licenciadas/proprietárias do Canva, o navegador pode cair nos fallbacks até que as fontes sejam disponibilizadas como webfont ou incorporadas pelo ambiente de desenvolvimento.

Para testar, abra `index.html` no navegador. Para o mapa e imagens carregarem, é necessário estar conectado à internet.
