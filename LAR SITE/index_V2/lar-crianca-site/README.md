# Lar da Criança Fermino Magnani — Home

Home em HTML, CSS e JavaScript com a identidade visual definida pela equipe.

## Identidade
- Verde: #6B8E72
- Azul: #79B8D1
- Amarelo: #FFD200
- Off-white: #FFF4D5
- Títulos: PAGKAKI Regular
- Textos: Now Regular

As fontes ficam em `assets/fonts/` e são carregadas localmente com `@font-face`.

## Conteúdo provisório
As imagens, depoimentos, parceiros, números e chave Pix são demonstrativos e devem ser substituídos pelos conteúdos oficiais do Lar.
